# 学位论文逻辑梳理

在整篇论文层面回答各研究点为何放在一起、如何共同支撑一个总体主张。研究点内部可用 3W2H。若任务聚焦一篇小论文或一个独立研究点，直接按 3W2H 梳理即可。已有总纲时，先还原现稿的论证和证据，再给出调整后的框架。

## 从问题推导研究内容

| 环节 | 应写出的内容 |
| --- | --- |
| 研究背景与现状 | 在什么具体情境中出现了什么重要现象？围绕它说明最相关的研究已经做到哪一步。 |
| 研究缺口与关键挑战 | 哪个缺口影响现有解释、测量、预测或决策？解决它最难的地方是什么？只保留能推出总体科学问题的内容。 |
| 总体科学问题 | 用一句话界定整篇论文要回答的问题或有共同约束的一组问题，注明研究对象、条件和边界。概念宽泛时，检查现有工作究竟共同解释了什么。 |
| 总体研究目标 | 用一句话说明完成研究后希望解释、测量、预测或干预什么，以及用什么结果判断目标是否达成。 |
| 各研究点 | 每点写清子问题、独立贡献、关键方法、验证依据和对总体目标的作用。章节是论证的组织形式。数据处理、系统搭建和消融通常支撑研究点。数据集、系统或评测若解决了独立可检验的问题，也可以成为研究贡献。 |
| 总体结论与验证 | 把总体主张逐条对到对应证据。说明跨点证据如何互相补充，以及各自成立的范围。完成度不同的研究点应明确标记。 |

## 检查研究点能否共同支撑主线

- **递进关系**。写清前一个研究点产出的哪项结果、数据、表征或方法被后一个点用来回答子问题。检查前置证据出现变化时，后续结论会怎样变化。
- **并列或互补关系**。写清各点回答的是共同问题的哪些方面，或者从哪几种条件交叉验证同一个主张。共用领域、数据集或代码时，可以在图上标明资源复用，再检验它们是否还有实质论证联系。若现有材料只能支撑较窄的共同主张，应据此收窄表述。
- **研究点作用**。试着删去某一点，判断会失去哪个子问题的答案、哪个必要前提、哪一类补充证据，或哪个适用范围。对于旨在交叉验证的研究点，也检查删去后证据是否变弱。若影响只在章节结构或实现细节，考虑把该点放到支撑工作中。研究点数量由问题和证据决定。
- **验证与边界**。对每个总体主张，列明支持它的研究点、对应证据和适用条件。有依赖跨点联动的主张时，标出需要的联合验证。若各项分别验证，说明它们如何共同支撑总体主张，给出可比条件与推断边界。只在口径可比时作跨点比较。
- **进度与证据**。按需标注已有证据、进行中、拟开展和证据不足。拟开展的研究点写预期观察与验证条件。若总体结论依赖待检验的关键假设，说明该假设不成立时，已有证据仍然支持什么。

## 输出格式

1. **总体故事线**。用一段话讲清缺口如何引出总体科学问题、总体目标，以及各研究点如何共同回答。
2. **研究内容表**。默认列出研究点、科学子问题、独立贡献、关键方法、验证证据或方案、与总体目标和其他研究点的关系。需要时补证据状态。单个研究点要详细展开时，按 3W2H 写一套。
3. **总体研究框架图**。完整梳理时，默认给一张图，串起缺口、总体科学问题、研究点与总体目标。明确标出递进和并列关系，给重要连接标明传递的产出、共同约束或支持的主张。按材料区分已验证与待验证的联系，并注明仅共享资源的连接。交付前检查方向、标签和证据状态。
4. **最需要修正的逻辑断点**。审查学生现稿时，优先指出一到三个影响总体论证的问题。每条尽量定位到原文段落、章节或幻灯片，说明目前怎样论证、哪条总体主张受影响、建议改哪一句或调整哪一处研究点关系。材料不足时，注明仍需核实的具体信息。
